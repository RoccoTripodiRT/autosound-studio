# 🔊 AutoSound Studio V4 - Engenharia de Som Automotivo

O **AutoSound Studio** é uma ferramenta interativa desenvolvida para auxílio a instaladores, entusiastas e projetistas de som automotivo.

## 🚀 Funcionalidades
* **Dimensionamento Elétrico:** Cálculo de consumo senoidal (A) e musical dinâmico com base em sistemas de 12.6V e 14.4V.
* **Casamento de Impedância:** Verificação automática de conexões em Série, Paralelo e Bridge.
* **Bitolas de Cabos:** Cálculo exato de cabos de alimentação (mm² / AWG) e tabela de fiação recomendada para alto-falantes.
* **Diagramação Visual:** Desenho gráfico automático do esquema de ligação no HTML5 Canvas.
* **Catálogo Integrado:** Sugestões de amplificadores, fontes, processadores DSP e falantes do mercado nacional.

## 🛠️ Tecnologias Utilizadas
* HTML5 / Canvas API
* CSS3 (Design responsivo e Cyberpunk UI)
* JavaScript puro (Vanilla JS)
